## Sign-off sheet

### 1. What changed
- **The phone app works.** On `/me/`, you or Mum can:
  - write a note (up to 280 characters, with a counter)
  - take or choose a photo, see a preview and send it; with more than one space, pick where it goes
  - see each moment's delivery: waiting, sending, or couldn't send with the reason, "Réessayer" and "Supprimer"
  - see the last 10 moments sent
- **Offline:** a moment, photo included, waits on the phone and goes when the desktop is back. A quiet line says "Vous êtes hors ligne…".
- **Home screen:** the app installs on Android and iPhone, and opens offline.
- **Displays** show a new moment within a second or two, as in M3. Long notes (up to 280 characters) now fit; short ones keep their size.
- **Behind the scenes:**
  - the server accepts photos up to 40 MB and refuses bigger ones before reading them
  - the whole UI is now Preact (ADR 11), with the French in `djangojs.po`

### 2. How to test it yourself
1. **Android phone:** open Coucou, pair it as your device, confirm your name. Write a note, add a photo, send. Both displays should show it within a few seconds, and the phone's list should empty.
2. **Two spaces:** if you control two, pick the other space in the list and send. It should arrive there. (This was broken until the review: m4-F1.)
3. **iPhone, home screen first** (D9):
   1. Safari → `/` → Share → Add to Home Screen.
   2. Open Coucou from the home screen and pair *inside* it.
   3. Turn on airplane mode, send a note, close the app.
   4. Turn airplane mode off and open the app. The note should arrive **once**.
4. **Desktop off:** stop the desktop, post from a phone (it waits), start the desktop. The displays should update.
5. **A big photo through Funnel:** send a full-resolution phone photo (10–20 MB) over mobile data. This is the one part tests couldn't cover: they ran the real server locally, not through Tailscale Funnel.
6. **French:** read the phone screens in French. Tell me anything that sounds stiff; the tone review found some (fixed in m4-F8).

## The juniors' code, honestly

**Overall: good enough to build on, not good enough to ship unreviewed.** The modules are small, readable and follow the worked example's shape: props in, callbacks out, `gettext()` everywhere, `useState` for local state. `thumbnail.js` and `sent_log.js` are clean and would pass any review. The weaknesses repeat:
- **Tests check presence, not content.** "An item appears" rather than "the item shows its note and thumbnail". That's how m4-F2 slipped through.
- **Tests drive the code from JavaScript instead of as a person would.** They dispatch `submit` or set `value` directly, which bypasses the disabled Send button and `maxlength`. So they test states nobody can reach, and miss the path a person takes (m4-F1).
- **Masking instead of fixing.** An undecodable test image was "fixed" with a silent `catch`. A test pinned the new font size and called it "the same". A dummy module was created to satisfy the layout gate.
- **Contract drift where the ticket was long.** m4-06 skipped the D6 mapping the ticket spelled out. m4-08 built a separate sent-log component instead of the `status: "sent"` items the ticket asked for (acceptable, but unasked).
- **Dead code:** unused refs in `compose.js`, a style constant in `me.js` that was never rendered, a no-op `interpolate`.
- **French:** correct (accents, `vous`), but plain rather than warm. One phrasing repeated M3's m3-F5 ("moment… pour le moment").
