## Outcome

On `/me/`, a person (the owner, Mum, later the sister on iPhone):
- takes or chooses a photo and/or writes a note (up to 280 characters), sees a preview, and sends it to a space (a picker appears only when they can post to more than one)
- sees each moment's delivery: waiting, sending, sent ✓, or couldn't send (with the reason, Try again and Remove)
- can send while the desktop is off: the moment, photo included, waits on the device and goes when the server is back (on opening the app, when it comes back to the foreground, when the network returns, and every 30 s while it's open)
- can install `/me/` to the home screen (Android and iPhone), and it opens offline

The displays show the new moment within a second or two of delivery (M3).

**Not in M4:** reactions in the sender app and the server's list of sent moments (M5), the display's port to Preact and the gallery (ADR 10; see ADR 11 item 3).

## Decisions

The contracts between pieces (ADR 07 item 16). A ticket that needs a different one says `BLOCKED.md`.

- **D1 Components ([ADR 11](../adr/11-preact-ui.md)):**
  - Preact + htm from `coucou/static/coucou/vendor/preact-htm.js`
  - one concept per module in `coucou/static/coucou/js/<name>.js`, tested in `tests/browser/test_<name>.py`
  - strings through `gettext()`, with the French in `coucou/locale/fr/LC_MESSAGES/djangojs.po` and `.mo`
  - worked example: `name_form.js` (L0)
- **D2 Page data:**
  - `/me/` renders `coucou/templates/coucou/me.html`: a shell with `<div id="app">` and `json_script` `me-data`
  - the data is `{display_name, name_confirmed, spaces: [{id, name}]}`, where `spaces` are the ones the person may post to, ordered by name
  - `me.js` mounts the app
- **D3 Outbox event** (what `Compose` hands to `onSend`):
  - `{id: crypto.randomUUID(), type: "content.posted", space: <id>, created_at: <ISO time of Send>, payload: {note?}, photo?: {bytes: ArrayBuffer, type}}`
  - the photo's bytes are read when queued; iOS can lose access to a picked file later
  - no `note` key when the note is empty
- **D4 Outbox API** (`outbox.js`, lead; built in L2):
  - `enqueue(event)`, `flush()`, `pending()`, `retry(id)`, `discard(id)`, `startOutbox({onChange, onSent, keepRefused})`
  - an event may carry `local`: the sender's own data (its thumbnail, `local: {thumb}`), kept on the device and never sent
  - `pending()` lists items oldest first: the event as queued, with the photo as `{type, size}` (never the bytes), `status: "waiting" | "sending" | "refused"` and, when refused, the server's `code` (or `null`)
  - `onChange()` is awaited after every change, so it should be quick; `onSent(item)` gets each delivered item, in `pending()`'s shape
  - the sender uses `keepRefused: true`: a refused moment stays until the person removes it or tries again; the display keeps dropping refused reactions
- **D5 `POST /api/events` for moments:**
  - **Request:** a note alone is JSON, as for reactions; with a photo, `multipart/form-data` with an `event` part (the same JSON, without `photo`) and a `photo` part (the file). Either way the request carries `sent_at`.
  - **Limits** (settings): `COUCOU_MAX_PHOTO_BYTES` 40 MB for the photo, and `COUCOU_MAX_UPLOAD_BYTES` (that plus 64 KB for the event and the multipart envelope) for the body
  - **Answers:** 201 stored, 200 duplicate (a retry)
  - **Errors, each with a `code` the client translates:**
    - 400: `note_too_long`, `empty_moment`, `photo_format`, `photo_unreadable`, `photo_too_large` (too many pixels)
    - 404: `space_not_found`
    - 413: `too_large` (over 40 MB)
  - anything else shows a generic "couldn't send"
- **D6 Component props:**
  - `Compose({spaces, onSend})`
  - `Delivery({items, onRetry, onDiscard})`, where items are `{id, note, thumb, status: "waiting" | "sending" | "sent" | "refused", code, at}`
  - `thumbnail(file, {max = 320}) → Promise<string>`, a JPEG data URL
- **D7 Client limits:** a note of at most 280 characters, with a counter; a photo of type `image/*` and at most 40 MB (`40 * 1024 * 1024` bytes), checked before queueing.
- **D8 Local memory (`localStorage`):**
  - `coucou-space`: the last space chosen
  - `coucou-sent`: the last 10 delivered moments, as `{id, note, thumb, at}`
  - M5 replaces the sent list with the server's list, reactions included
- **D9 iPhone:**
  - Safari → Add to Home Screen from `/` → open the app → pair inside it, because a home-screen app's storage is separate from Safari's
  - the manifest's start and scope are `/me/` ([ADR 05](../adr/05-identity-and-me.md))

## Settled by L0

- `xgettext` reads `gettext()` inside htm templates, nested ones included, so strings sit where they're shown. The fallback (constants) isn't needed. `test_translations.py` guards it.
- Browser tests get the real `/jsi18n/` (English) from the harness rather than a stub, and mount components with `mount()` (`tests/browser/conftest.py`).
- The disconnect question is its own component (`disconnect.js`). `me.js` holds the app's state and the calls to `/api/me`.
