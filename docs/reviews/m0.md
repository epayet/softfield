## Decisions made during M0 (please glance at these)

- **`django-stubs-ext` is a runtime dependency.** It's tiny, and it lets admin classes carry type parameters that strict mypy needs. This is the documented approach.
- **The default time zone for history-folder names is `Europe/London`.** Change it with `COUCOU_TIME_ZONE`.
- **Headless Claude jobs never run git.** The runner commits whatever Claude changes. Claude reports its decision in a small `decision.json`, and the runner moves the task files.
- **Some ruff rules are off:** `RUF012` (flags normal Django class attributes), `PT018` and `S603`. These are noise in this codebase.
- **mypy is strict for tests too,** with only annotation requirements relaxed.

## Workflow observations (for learning, no change proposed)

- **Fixed overhead per local call:** OpenCode sends about **6,400 input tokens** even for "reply OK", made up of its system prompt, tool definitions and AGENTS.md. Every model step re-sends the whole conversation, so a 20-step task can easily process 200–400k input tokens locally. That's free locally but slow. Session reports show "average input per step" so we can see context bloat.
- **Cold start:** the first request after LM Studio unloads the model costs about **40 s** of JIT loading with your settings. The runner warms up before every OpenCode call, so the cost is paid once per session and shows up in reports.
- **Context:** your LM Studio settings load Qwen with **157,440 tokens** of context, not the 64k in the brief. OpenCode is told the real number, and the runner warns if the two ever differ.
- **Guardrails that matter most** are the gates that stop the model gaming the tests: existing tests unchanged, allowed files only, protected paths. The loop tests simulate exactly those attempts, such as a model gutting a test file.
- **Calibration will tell us about task size.** The format allows 1–3 files and about 150 changed lines. Qwen-35B-A3B may do better with even smaller tasks and a very explicit Context. We'll measure first-attempt pass rates rather than guess.
