## Workflow observations

- **Every M1 proper task passed on the first attempt (3/3), with no escalations.** Each took 51 s to 1.4 min of model time plus 3–4 s of gates. That fits the calibration advice to keep specs short (Context ≤ ~60 lines, Steps ≤ 5), paste every signature with its backticked source path, and put the key instruction last. ADR 01's fixes were in place.
- **Calibration (m1-01, m1-02) cost 2 headless escalations,** both caused by spec mistakes, not model errors. No spec mistakes happened after the fixes.
- **Per-step input** was about 8.9k tokens in the M1 proper session, down from about 11k in calibration. Shorter Context helped, but OpenCode's fixed ~6.4k overhead still dominates tasks this small.
- **The review found only one issue worth fixing, and it came from the spec, not the model.** The m1-02 spec never considered prod. The model followed Steps exactly, so review is the place to catch what the specs leave out. Lesson for task-writing: for any command that writes data, the spec should say where it may run.
- **Room to grow:** at 3/3 first-attempt passes on ~30–40-line diffs, M2 could try slightly larger tasks (≤ ~80 lines) on non-protected work. Pairing itself stays with Claude.
