**Security:** besides m3-F1, I checked:
- the media view: only through `readable_events`, 404 for anything else, `MEDIA_ROOT` never served, path traversal refused in `_inside`, and every stored file is a fresh re-encode

- **Reworded in m3-09:**
  - "Encore un instant…" → "Un petit instant…" ("encore" suggests it's been slow already).

  - "Hors ligne : affichage du dernier moment." → "Hors ligne : voici le dernier moment." (a nominal, technical phrasing).

  - "Veuillez écrire un prénom." → "Écrivez votre prénom."

## Round 2

I re-reviewed the fix diff `ecd5104..main` (round 1's Claude fixes and m3-09).

| ID | Result |
|---|---|
| m3-F1 | **Resolved.** A few details checked. The watcher closes moved streams *before* it publishes that tick's events, so a moved screen gets nothing new from its old space. The `reset` travels as a position-0 notice, and nothing else can have position 0 (SQLite rowids start at 1). The heartbeat keeps its own deadline, so a busy stream still re-checks every 20 s.
