- Escalation m1-02-seed-demo (requeue): The runner's pre-flight check rejected the task before the local model ran (0 attempts), so the model didn't get anything wrong. The spec was the problem.
Pre-flight collects backticked paths in Context and requires every `class`/`def` pasted there to be defined in one of those paths or in the task's `files:`. The spec named the model files only inside `# coucou/models/...` code comments, which pre-flight doesn't count as paths. It also said "the `__init__.py` files", which reads as a bare, non-existent path.
Fix: Context now names `coucou/models/accounts.py`, `spaces.py` and `devices.py` as backticked full paths, plus both `__init__.py` files. Nothing else changed.
Lesson for task-writing: whenever Context pastes a signature, put its source file in backticks with the full repo path, and never put a bare filename in backticks. A small `runner check-task <file>` (pre-flight only) that I'd run before committing a spec would catch this. It's a runner addition, not a rule change.
