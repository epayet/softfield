## What went well
- `xgettext` reads `gettext()` inside htm templates, so the fallback isn't needed. A regression test guards it.
- The domain layer (`post_content`, `validate_event`, `encode_photo`) already did most of L1. The view was mostly wiring.
- Checking the real uvicorn caught what the unit tests can't: a declared 43 MB body is refused in 0.5 ms without being read, and a chunked one is cut off.

## What didn't
- Two mypy errors went into the L2 commit, because I ran only pytest before it. Nothing ran on that `main`, but every junior gate would have failed. **Lesson:** run ruff, mypy and pytest before every lead commit, not only at the end.
- Test-harness traps cost several rounds, and all now sit in `preact.md` or in comments:
  - `page.evaluate("x = promise")` waits forever
  - `serviceWorker.ready` never resolves outside the scope
  - `page.route` doesn't see a service worker's own fetches
  - Playwright leaves an event loop running, so `asyncio.run` fails in later tests
- The ticket review found gaps that the dry run can't see:
  - m4-06 used `thumbnail` without depending on m4-03
  - m4-05 styled screens that only exist after m4-06
  - m4-03 asked a junior to write a binary JPEG fixture it can't create

  They were fixed before any junior ran.
